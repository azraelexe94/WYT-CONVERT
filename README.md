## 📌 Sobre o projeto
O **WYT CONVERT** foi desenvolvido por **Azrael.exe** após diversos pedidos da comunidade.  
É um conversor rápido, prático e sem dependências externas para trabalhar com arquivos do WYD.

---

## ✨ Funcionalidades
- Conversão em massa (**vários arquivos de uma vez**)  
- Suporte completo a **WYT ⇄ TGA ⇄ OZT**  
- Preview integrado das imagens antes da conversão  
- Layout compacto e intuitivo  
- Apenas **1 único .exe**, sem DLLs ou arquivos extras  
- Ícone personalizado no executável e no formulário  

---

## 🚀 Como usar
1. Abra o programa e selecione a pasta com seus arquivos `.wyt` ou `.tga`.  
2. Escolha o modo de conversão desejado.  
3. Clique em **Converter Selecionados**.  
4. Os arquivos convertidos serão salvos automaticamente nas subpastas `out_tga`, `out_wyt` e `out_ozt`.
